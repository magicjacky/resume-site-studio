This template demonstrates a premium light resume site for a fictional operations-assistant candidate. It uses the same visual ambition as the repository showcases: immersive hero composition, layered light, evidence-led metrics, varied section layouts, responsive motion, and a strong editorial rhythm.

- Replace every name, date, metric, school, role, and sentence with verified user material.
